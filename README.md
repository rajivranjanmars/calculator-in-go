# Calculator in Go

An interactive terminal calculator for integer arithmetic, organized into a command-line entry point and a reusable `functions` package.

## Usage

Use `go run .` to launch the prompts. Enter two integers followed by an operator; `x` exits. Use `go test ./...` to check the packages.
